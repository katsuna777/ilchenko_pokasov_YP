# Медицинский центр «ДокторМаг»

Информационная система для просмотра сотрудников медицинского центра и работы с записями на приём. Приложение разработано на C# с использованием Windows Forms и MySQL.

## Возможности

- вход сотрудника по логину и паролю;
- вход клиента по фамилии и номеру полиса ОМС;
- просмотр списка сотрудников в роли гостя;
- поиск сотрудников по доступным полям;
- сортировка по ФИО и направлению;
- фильтрация по статусу, типу посещения, направлению и смене;
- отображение количества выведенных и общих записей;
- выделение временно отсутствующих сотрудников и запрет записи к ним;
- первичная запись пациента на приём;
- просмотр всех посещений для сотрудника и собственной истории для клиента;
- поиск, фильтрация и сортировка записей;
- повторный приём с автоматическим заполнением данных пациента и врача;
- выход из учётной записи и возврат к форме входа.

## Необходимые условия

- Windows 10 или Windows 11;
- .NET 8 SDK;
- Visual Studio 2022 версии 17.8 или новее (либо `dotnet` CLI);
- MySQL 8 с доступом к серверу, указанному в настройках подключения.

## Установка и запуск

1. Создайте базу данных и таблицы из скрипта `Documents/schema.sql`:

   ```bash
   mysql -h <host> -P <port> -u <user> -p < Documents/schema.sql
   ```

2. Загрузите данные из скрипта `Documents/import.sql`:

   ```bash
   mysql -h <host> -P <port> -u <user> -p < Documents/import.sql
   ```

3. Проверьте параметры подключения в файле `DoctorMag/Data/Database.cs`.
4. Откройте решение `DoctorMag.sln` в Visual Studio 2022.
5. Соберите и запустите проект `DoctorMag`.

Через командную строку:

```bash
dotnet restore DoctorMag.sln
dotnet run --project DoctorMag/DoctorMag.csproj
```

## Учётные записи

Сотрудники входят по логину и паролю из таблицы `users`. Клиент вводит свою фамилию и номер полиса ОМС из таблицы `patients`. Для просмотра сотрудников без входа предназначена кнопка «Просмотр сотрудников как гость».

## Структура проекта

- `DoctorMag/Forms` — форма входа, справочник сотрудников и записей, форма записи на приём;
- `DoctorMag/Data` — работа с базой данных и правила записи;
- `DoctorMag/Models` — модели сотрудников, пациентов и посещений;
- `DoctorMag/Resources` — логотип, изображения сотрудников и заглушка;
- `Documents/schema.sql` — структура базы данных;
- `Documents/import.sql` — данные для импорта;
- `Documents/ER-диаграмма.pdf` — ER-диаграмма;
- `Documents/Сценарии тестирования.docx` — сценарии тестирования;
- `Documents/Руководство пользователя.docx` — руководство пользователя.
