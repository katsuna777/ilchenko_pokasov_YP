# Школа иностранных языков «Леарн»

Информационная система для просмотра услуг школы, работы с каталогом и записи клиентов на занятия. Приложение разработано на C# с использованием Windows Forms и MySQL.

## Возможности

- просмотр списка услуг с наименованием, стоимостью, длительностью, скидкой и изображением;
- поиск по названию и описанию услуги в реальном времени;
- фильтрация по размеру скидки;
- сортировка по стоимости (по возрастанию и убыванию);
- отображение количества выведенных и общих записей;
- режим администратора с кодом доступа `0000`;
- добавление, редактирование и удаление услуг;
- проверка уникальности названия и допустимой длительности услуги;
- запись клиента на выбранную услугу с выбором даты, времени и клиента из базы;
- просмотр ближайших записей.

## Необходимые условия

- Windows 10 или Windows 11;
- .NET 8 SDK;
- Visual Studio 2022 версии 17.8 или новее (либо `dotnet` CLI);
- MySQL 8 с доступом к серверу, указанному в настройках подключения.

## Установка и запуск

1. Восстановите базу данных из скрипта `Database/CreateDatabase.sql`:

   ```bash
   mysql -h <host> -P <port> -u <user> -p < Database/CreateDatabase.sql
   ```

2. Проверьте параметры подключения в файле `SchoolLearn/Data/DatabaseSettings.cs`.
3. Откройте решение `SchoolLearn.sln` в Visual Studio 2022.
4. Соберите и запустите проект `SchoolLearn`.

Через командную строку:

```bash
dotnet restore SchoolLearn.sln
dotnet run --project SchoolLearn/SchoolLearn.csproj
```

## Режим администратора

Нажмите кнопку «Вход администратора» и введите код `0000`. В этом режиме становятся доступны добавление, редактирование и удаление услуг, а также запись клиента и просмотр ближайших записей.

## Структура проекта

- `SchoolLearn/Forms` — формы каталога, редактирования услуги, записи клиента и административного входа;
- `SchoolLearn/Controls` — карточка услуги;
- `SchoolLearn/Data` — настройки подключения и работа с базой данных;
- `SchoolLearn/Models` — модели услуг, клиентов и записей;
- `SchoolLearn/Services` — бизнес-правила, сессия администратора и сообщения;
- `SchoolLearn/Assets` — логотип и изображения услуг;
- `Database/CreateDatabase.sql` — структура и данные базы.
